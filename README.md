# MEDICO – Healthcare Management System

MEDICO is a web-based healthcare application designed to connect patients and doctors through a single platform.

### Features
- Patient and Doctor Registration & Login
- Forgot Password
- Doctor Profile Management
- Doctor Verification System
- Find Doctors by Specialization and Location
- Appointment Booking
- Online Consultation and Home Visit Options
- Home Visit Address Management
- Patient Medical Records
- Patient–Doctor Messaging
- Admin Dashboard

### Tech Stack
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- JSON-based Data Storage

MEDICO aims to make healthcare services more accessible, convenient, and connected.
